# Spooky Paint - Color Sort — передача проекта

Этот файл — первое, что нужно прочитать (человеку и ChatGPT). Здесь всё, чтобы продолжить разработку без доступа к прошлым чатам.

**Совет для работы с ChatGPT:** в начале каждого нового чата загрузите в него этот файл и `game/CLAUDE.md`, а потом те файлы кода, которые нужно менять. ChatGPT не помнит прошлые разговоры, поэтому всё, о чём договорились, дописывайте в раздел «Зафиксированные решения» ниже.

## Что это за игра
HTML5-игра для портала QS Play (play.quartsoft.com, раздел Spooky Games к Хэллоуину).
Смесь двух механик:
- **Сортировка красок (water sort)** — основной геймплей. В колбах перемешаны слои краски, игрок переливает их, пока в каждой колбе не останется один цвет.
- **Раскраска по номерам** — мета. Каждая собранная колба даёт 2 единицы краски своего цвета, каждая клетка картины стоит 1 единицу. Краска кончилась — идёшь сортировать ещё.

Сеттинг: мастерская ведьмы-художницы, стиль cozy spooky (мило, не страшно). Аудитория портала: в основном женщины 55–60+ из США, Великобритании и Европы, любят спокойные головоломки (судоку, маджонг, фермы).

## Состояние на 26.11.2026
Играбельный прототип:
- 3 картины: тыква на заборе (24 клетки, 3 цвета), кот ведьмы (36 клеток, 4 цвета), котёл (48 клеток, 5 цветов);
- 14 уровней сортировки, каждый проверен солвером;
- 2 отмены на уровень, лимит ходов, проигрыш и рестарт с той же раскладкой;
- паутина (скрытые нижние слои) с картины 3;
- обучение рукой-подсказкой, оживление готовой картины, галерея, синтезированные звуки (без аудиофайлов), русский и английский;
- интеграция с QS Play SDK через одну обёртку, сохранение прогресса.

## Как запустить
1. Распакуйте архив.
2. Откройте `game/index.html` двойным кликом в браузере (Chrome, Edge, Firefox). Сервер не нужен. GitHub Pages не используем.
3. Вне портала SDK работает в mock-режиме, прогресс хранится в localStorage браузера.
4. `game/index.html?sdk-debug=1` — показывает панель логов SDK.
5. Начать заново: в консоли браузера (F12) выполнить `localStorage.clear()` и обновить страницу.

Если какой-то браузер блокирует локальный файл, раздайте папку простым сервером: `cd game` и `python -m http.server`, затем откройте http://localhost:8000.

## Зафиксированные решения (не менять без Артема)
Эти правила важнее дизайн-документа, если они расходятся.

**Сортировка**
- В колбе до 4 слоёв. Переливать можно в пустую колбу или на тот же цвет, переливаются все верхние слои этого цвета, сколько влезет.
- 2 отмены на уровень. Нет ходов и нет отмен = уровень проигран и начинается заново с той же раскладкой.
- Лимит ходов на каждый уровень (поле `moves` в `js/levels.js`): кратчайшее решение плюс запас, который зависит от сложности. Лёгкий +60% +4, средний +40% +3, сложный +25% +2 (константа `SLACK` в генераторе). Кончились ходы до победы — проигрыш. Отмена возвращает ход.
- Никаких помощников (лишняя колба, подсказка) и платных бустеров.

**Сложность уровней**
- Порядок сложности случайный: лёгкий, средний и сложный выпадают в пропорции 2:3:1.
- После сложного уровня всегда идёт лёгкий.
- Уровень 1 (обучение) всегда лёгкий.
- Игрок никогда не видит, какой сложности уровень (никаких значков и подписей).
- Генератор детерминированный (параметр `SEED`), у всех игроков одинаковые уровни.

**Краска и картины**
- 1 картина = 1 палитра. Краска не переходит на следующую картину, остаток сгорает.
- Колба = 2 единицы краски, клетка = 1 единица.
- Колбы в уровне — цвета текущей картины, в первую очередь недостающие. Если цвета уже хватает, колба может попасться, но краску не даёт (метка «хватает»).

**Портал и запреты**
- Нельзя: гемблинг и случайные награды (Plinko, слоты, лутбоксы), классические игральные карты, хоррор.
- Своих экранов логина нет, гости играют сразу. Игра стартует сразу или за один клик.

**Визуал**
- Cozy spooky: мило, насыщенно, «сделано руками». Без рамок вокруг игры и декоративных надписей.
- Без типичных «веб-приложение/AI» приёмов: карточек с серыми тенями, градиентных кнопок, эмодзи, ВСЕХ ЗАГЛАВНЫХ. Кнопки — объёмные игровые с тёмным нижним краем; поверхности — дерево, бумага, стекло.
- Текст в игре только тот, что нужен игроку. Каждую строку добавлять сразу на ru и en.

## Правила для кода (важно сказать ChatGPT)
- Только чистый JavaScript и обычные `<script>`. Без фреймворков, без сборщиков, без npm-зависимостей в рантайме.
- Все вызовы QS Play SDK — только через `js/sdk-adapter.js`. Жизненный цикл: `loadingStart/loadingStop` вокруг загрузки; `gameplayStart`, когда игрок может действовать; `gameplayStop` на оверлеях, в галерее и при потере фокуса. Без дублей.
- Сохранение — один JSON под ключом `save` с полем версии `v`. Меняете формат — повысьте `v` и добавьте миграцию старых сохранений в `boot()` в `main.js`.
- `js/levels.js` и `js/pictures.js` не править руками: менять генераторы в `tools/` и перегенерировать.
- Правила сортировки живут в двух местах: `js/rules.js` и `tools/generate-levels.mjs`. Меняете одно — меняйте и другое, иначе солвер будет пропускать нерешаемые уровни.
- Все пути относительные, сборка меньше 50 МБ (сейчас около 300 КБ).
- Маленькие изменения: одна задача — одно изменение. После каждого изменения открыть игру и проверить руками.

## Команды для разработки
Нужны Node.js 18+ (для генераторов) и, по желанию, Python 3.10+ с Playwright (для автотестов).
```
cd game
node tools/build-pictures.mjs      # пересобрать js/pictures.js после изменения картин
node tools/generate-levels.mjs     # пересобрать js/levels.js (после любой правки картин)
pip install -r tools/requirements.txt && python -m playwright install chromium
python tools/check-labels.py                 # каждый номер стоит на своей видимой клетке
python tools/playtest.py out/ 390 844 4      # автопрохождение на экране телефона, скриншоты в out/
python tools/playtest.py out/ 1280 720 14    # все уровни на экране компьютера
```
`tools/preview-pictures.html` показывает все картины пустыми с номерами и раскрашенными.

## Что осталось сделать
Порядок примерный, приоритеты согласовать с Артемом.

1. **Картины 4–6** по дизайн-документу: летучие мыши над домом с привидениями (6 цветов, 60 клеток), скелет-садовник с тыквами (7/72), праздник призраков на кладбище (8/90). Пайплайн арта описан в `game/docs/AI_DEVELOPMENT.md`, раздел 5.
2. **Закупоренная колба** с картины 5: открывается, когда соберёшь соседнюю. Нужно добавить и в `js/rules.js`, и в солвер генератора.
3. **Обсудить с Артемом:** генератор иногда даёт сложным уровням только одну пустую колбу, иначе они получались недостаточно сложными.
4. **Сложные картины** (цель: дольше игра, до 300 цветов на высоких уровнях). Тест лежит в `complex-pictures/`, там же открытые вопросы: размер номера на каждой клетке, экономика для цветов с 1–2 клетками, схема сортировки для 100+ цветов.
5. **Финальный арт** картин от художника (сейчас картины нарисованы кодом).
6. **Аналитика:** события старта и результата уровня, рестартов, отмен, закрашивания, завершения картины; отмены и проигрыши по типам сложности.
7. **Локализация** на 9 языков портала (сейчас только ru и en).
8. **Арт для страницы на портале:** иконка 512×512, обложка 1200×630, 3–8 скриншотов 1920×1080.
9. **Проверка** внутри iframe портала и на 2–3 реальных телефонах (особенно мелкие клетки на картинах 2 и 3). Чек-лист публикации — `game/docs/AI_DEVELOPMENT.md`, раздел 7.
10. Открытые вопросы из дизайн-документа: «волшебная кисть» как награда за картину; что делать после последней картины, пока нет новых.

## Отличия дизайн-документа от игры
- В документе сложность идёт строгими блоками по 6 (2-3-1). В игре — случайно 2:3:1 с правилом «после сложного лёгкий», уровень 1 лёгкий.
- В документе нет лимита ходов. В игре он есть.
- В документе 6 картин и около 35 уровней. В игре пока 3 картины и 14 уровней.
- Узоры на этикетках для дальтоников, фоновая музыка и «предложение войти» после первой картины пока не сделаны.
- `game/README.md` пишет, что проверки GitHub Actions идут на каждый push. Это устарело: они запускаются только вручную, и для работы без GitHub они не нужны.
