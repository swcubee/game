# Spooky Paint - Color Sort

Хеллоуинская раскраска по номерам, краски для которой игрок добывает в уровнях сортировки (water sort).
HTML5-игра для портала [QS Play](https://play.quartsoft.com): чистый JavaScript без фреймворков и сборщика,
интеграция с QS Play SDK.

## Как запустить
Откройте `index.html` в браузере или раздайте папку любым статическим сервером
(например, `npx serve .` или `python3 -m http.server`). Вне iframe портала SDK работает в mock-режиме,
прогресс сохраняется в localStorage. Добавьте `?sdk-debug=1` к адресу, чтобы видеть лог SDK.

Сбросить прогресс: в консоли браузера `localStorage.clear()` и перезагрузить страницу.

## Что в игре
- 3 картины (24, 36 и 48 клеток; 3, 4 и 5 цветов). Уровни сортировки собираются в игре на лету под нужную картине краску, их не ограниченное число.
- Ограниченная краска: собранная колба = 2 единицы, клетка = 1 единица, 1 картина = 1 палитра.
- 2 отмены на уровень, проигрыш при отсутствии ходов, рестарт с той же раскладкой.
- Сложность уровней случайная (после сложного всегда лёгкий) и игроку не показывается, каждый уровень проверен солвером. Паутина (скрытые слои) с картины 3.
- Обучение рукой-подсказкой на первом уровне и на первой раскраске.
- Оживление готовой картины, галерея, синтезированные звуки, русский и английский.

## Разработка
Нужны Node.js 18+ и Python 3.10+ (для автотестов).

```bash
npm run pictures                           # пересобрать js/pictures.js
npm run pool                               # пересобрать банк раскладок js/level-pool.js (~10 мин)
pip install -r tools/requirements.txt && python3 -m playwright install chromium
python3 tools/check-labels.py              # номер каждой клетки стоит на своей клетке
python3 tools/playtest.py out/ 390 844 4   # автопрохождение на экране телефона, скриншоты в out/
python3 tools/playtest.py out/ 1280 720 14 # все уровни на экране десктопа
```

## Проверки (CI)
На каждый push GitHub Actions ([`check.yml`](.github/workflows/check.yml)):
1. перегенерирует картины и падает, если `js/pictures.js` не закоммичен после правки генератора;
2. проверяет номера клеток;
3. проходит уровни в headless Chromium на телефоне и на десктопе;
4. прикладывает скриншоты (`screenshots`) и готовую сборку для портала (`spooky-paint-game`).

## Сборка для портала
Сборка — это сама папка игры: `index.html`, `css/`, `js/`, `fonts/`. Все пути относительные, размер около 300 КБ.
Готовый архив можно скачать из артефакта `spooky-paint-game` последнего запуска CI.
