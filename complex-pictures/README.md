# Сложные картины: тестовая «Домик ведьмы на тыквенной поляне»

Эксперимент от 25.10.2026. **В игру не встроен.** Цель Артема: на высоких уровнях картины должны быть намного сложнее (дольше игра, до 300 цветов).

Тестовая картина: 351 клетка, 110 цветов.

| Файл | Что это |
|---|---|
| `scene.mjs` | генератор сцены: строит области (клетки) в том же формате, что `game/tools/build-pictures.mjs` (кадр 360×480, области рисуются по порядку, поздние поверх ранних) |
| `analyze.mjs` | рендерит картину в Chromium, строит карту видимости и сам ставит номера: координаты `nx`, `ny` и размер шрифта `fs` для каждой клетки |
| `cottage-picture.json` | готовая картина в формате `js/pictures.js` (палитра + области + номера) |
| `cottage-numbers.svg/.png` | как картина выглядит пустой, с номерами |
| `cottage-colored.svg/.png` | как она выглядит раскрашенной |

Пересобрать (из этой папки, нужны Node.js 18+ и `npm i playwright` + `npx playwright install chromium`): `node analyze.mjs out/`. Скрипт сам берёт сцену из `scene.mjs` и пишет JSON, SVG и PNG в `out/`.

## Открытые вопросы перед встраиванием в игру
1. Размер номера и толщина контура нужны свои для каждой клетки: мелкие клетки иначе не читаются (в `cottage-picture.json` уже есть поле `fs`, но `js/paint.js` его пока не использует).
2. Много цветов с одной-двумя клетками, а колба даёт 2 единицы: краска будет сгорать впустую. Нужна другая экономика для таких картин.
3. Как сортировать 100+ цветов: в одном уровне столько колб не поместится. Нужна схема (например, уровень даёт только недостающие цвета группами).
